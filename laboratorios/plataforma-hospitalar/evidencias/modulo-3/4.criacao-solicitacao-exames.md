### Comando executado

```powershell
$body = @{
    beneficiario_id = "paciente-001"
    codigo_exame = "HEM-001"
} | ConvertTo-Json

Invoke-RestMethod `
    -Uri "http://localhost:18002/exames" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body
```

### Resultado

```text
beneficiario_id codigo_exame solicitacao_id situacao
--------------- ------------ -------------- --------
paciente-001    HEM-001                   1 solicitado
```
